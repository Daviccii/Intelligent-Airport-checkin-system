### Card Colors:

- 🟠 **Orange** - Revenue, Warnings, Caution
- 🔷 **Cyan** - Check-ins, Secondary

### Status Colors:
- 🟢 **Green** - Operational, Success, Online
- 🟠 **Orange** - Warning, Caution, Pending
- 🔴 **Red** - Critical, Error, Delay
- ⚪ **Gray** - Offline, Disabled

### Alert Colors:
- 🟢 Green left border = Success
- 🟠 Orange left border = Warning
- 🔵 Blue left border = Info

## Responsive Behavior

### On Desktop (1024px+):
- All 4 summary cards visible side-by-side
- All sections display full width
- Complete data visibility
- Charts fully sized

### On Tablet (768px - 1023px):
- Summary cards in 2 rows of 2
- Sections stack for better readability
- Touch-friendly spacing
- All features accessible

### On Mobile (< 768px):
- Summary cards stack vertically
- All sections single column
- Full-width cards
- Optimized for touch
- Swipe-friendly layout

---

## Animation Sequences

### Page Load:
1. Fade in up - Header (0.6s)
2. Fade in up - Summary cards (0.6s with 0.2s delay)
3. Fade in up - Sections (cascading delays)

### Card Interaction:
1. Hover - Lift and shadow (0.3s smooth)
2. Border - Scale in from left (0.3s)
3. Click - Modal opens with fade

### Data Refresh (Every 30s):
1. Pulse animation on cards
2. Shadow expands and contracts
3. Data updates smoothly
4. Timestamp refreshes
